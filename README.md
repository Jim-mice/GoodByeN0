# N0 Kernel Agent (retired archive)

N0 is a retired research engineering project. Its experimental execution has been permanently discontinued. This repository preserves the core implementation and hardware knowledge infrastructure for archival purposes.

No experiments, Provider calls, OJ evaluation, GPU qualification, or formal Episodes are authorized or supported by this archive. It is not a production-ready product. The latest G3 R4.6 path completed one real SSE Provider response and delivered Hardware tool results; its next Provider outcome remained unknown, and Profile delivery to the Agent was not proven. Do not describe R4.6 as production-reliable.

The repository contains source subsets, not deployable frozen Releases. Release manifests were not copied because this archive deliberately omits runtime data, Reference measurement records, receipts, databases, expert assets, and credentials. Exact source lineage is in `PROVENANCE.md`.

Hardware knowledge is limited to the frozen R5 hardware facts and their source record. Expert Knowledge content is absent. KernelBench task 40 and its MIT license are included as third-party material.

The source workspace had no Git metadata. This repository is a new local archive with no remote configured and has not been uploaded.
