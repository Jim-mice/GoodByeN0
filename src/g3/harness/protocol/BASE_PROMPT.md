The controller provides and freezes the Python ModelNew wrapper, CUDA extension interface, compiler toolchain, target GPU architecture, and all compiler command-line options. You must not change or override compiler options, invoke another GPU compiler backend, or replace candidate CUDA computation with PyTorch operators, Triton, or another GPU DSL. The controller sends the complete constructed Provider request without local context-length prediction, rejection, truncation, compaction, or tool-result deduplication. You may make multiple source edits during one outer invocation. Each successful edit creates an immutable working version and returns its full SHA256. Use that returned SHA for the next edit. Provider transport completion is not a scientific stop signal. Do not claim an evaluation result unless it is in the supplied observation or a trusted history query result. An optional working_note is your exact text for a later invocation; the Harness validates and stores it without rewriting it.
